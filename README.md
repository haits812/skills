# AI News Timeline — 2026-08-05 to 2026-08-18

生成AI関連ニュース15本と、オフショア人材・BPO・インドGCCに関する特集分析をまとめたポータブルHTMLです。

## 開き方

```bash
git clone https://github.com/haits812/skills.git
cd skills/ai-news-timeline-2026-08-05-18
```

その後、`index.html`をブラウザで開いてください。

- Windows: `start index.html`
- macOS: `open index.html`
- Linux: `xdg-open index.html`

HTMLと`assets/`は相対パスで接続されているため、フォルダ構成を保てばローカルで表示できます。画像と本文はオフラインでも閲覧でき、出典リンクを開く場合のみインターネット接続が必要です。
